# status.keston.co

Keston service status, built with Keston UI (Vite + Vue) and deployed as a static site on GitHub Pages. It is hosted separately from the services it reports on, so it stays up when they do not. Checks run live in the visitor's browser; incidents are posted by editing `public/incidents.json` (see INCIDENTS.md).

```sh
pnpm install
pnpm dev
```
